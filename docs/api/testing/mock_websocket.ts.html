testing/mock_websocket.ts

A WebSocket stand-in the test drives, for frontend code that constructs sockets itself (FrontendWebsocketClient and the clients built on it): install_mock_websocket swaps it in as globalThis.WebSocket, every socket constructed is recorded, and the test plays the server with fire_open, fire_message, fire_close and fire_error.

Run the real client over it rather than faking the client: its close-code rules, queue and reconnect then come along, where a fake re-encoding them drifts.
