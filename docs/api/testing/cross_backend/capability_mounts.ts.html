testing/cross_backend/capability_mounts.ts

Cross-backend suite holding a backend's mount flags to what it mounts, in both directions.

A capability flag gates the suites that need its surface: true runs them, false skips them. Nothing in those suites checks a false — a backend declaring cell_crud: false while mounting the cell verbs skips the cell suites, and its cell surface goes untested with no failure anywhere. And on a backend declaring every flag true, as fuz_app's own spine presets do, a check of the false direction alone would never run. So each flag a request can observe is probed once, and the observation must equal the declaration: true must answer as mounted, false as unmounted.

Each probe is the cheapest honest request — anonymous, so no setup state shapes the answer — and none of them answers a mounted surface with a 404. An unmounted path under /api answers 404: the spine's JSON route_not_found, or no body where a runtime drops a refused upgrade's body or a backend's own fallback answers /api paths.

  • RPC verbs (cell_crud: cell_create, cell_relations: cell_grant_create) — both spines look a method up before they authenticate the caller, so a mounted verb refuses an anonymous call 401 and an unmounted one answers method_not_found (404).
  • Auth-gated routes (sse on sse_path, account_status) — a mounted route refuses an anonymous GET 401.
  • The fact routes (fact_serving, fact_serving_admin_hash) — a malformed hash param: both spines validate a route's params ahead of auth, so a mounted route answers 400 invalid_route_params. (The cell route's masked 404 for a cell no row names can't tell itself from a bodiless unmatched 404.)
  • ready — GET /ready answers 200 {ready: true}, or 503 with schema_drift / db_unreachable (mounted, if drifted — the readiness suite fails that); unmounted, a 404 (any body — the spine fallback's plain text) or a 200 that isn't JSON (a static page).
  • WebSocket endpoints (ws on ws_path, ws_role_gated on the gated path) — a mounted endpoint refuses an anonymous upgrade 401.
  • ws_account_actions — account_verify sent on the keeper's session socket answers unless the endpoint lacks it (method_not_found). Needs ws: with ws declared false the probe is skipped when the flag is false too, and fails when it is true.

An answer that is neither the mounted nor the unmounted one fails the probe.

Unmounted controls. On a backend declaring every probed flag true, as fuz_app's spine presets do, no probe meets an unmounted surface, so a classifier reading every answer as mounted would pass. Each flag's own probe is also sent to its surface moved where no backend mounts anything (CAPABILITY_MOUNTS_ABSENT — the path under an absent segment, the method renamed), and must read as unmounted, on every backend. So a backend with a catch-all under /api, or an RPC dispatcher answering an unknown method, fails the controls: the suite rests on the spine's 404 and method_not_found for what isn't mounted.

The other flags are listed in UNPROBED_CAPABILITIES with why no request checks them, and each shows in the run as a skipped test carrying that reason. ProbedCapability and UNPROBED_CAPABILITIES together are exhaustive over BackendCapabilities by their types, so a new flag fails to compile until it is classified.

describe_spine_cross_suites runs this suite on every backend and refuses to exclude it, exclude one of its cases, or override any of its options: it checks the declarations every other suite gates on, so each path it probes is the one the suites gated on that flag send to — the backend config's, ws_role_gated's gated_ws_path, ready's ready_path, and the SPINE_ACCOUNT_STATUS_PATH that query_shape, token_scope_surface and request_target_conformance_wire (each gated on account_status) send to. A probe whose sibling suite the call excludes falls back to the spine default, and its failure names the remedy (path_notes). It runs cross-process only — in-process apps are assembled per test file, each mounting what its suite needs, so no one in-process declaration describes them, and the WS probes need a real socket.
