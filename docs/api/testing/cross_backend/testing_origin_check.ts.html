testing/cross_backend/testing_origin_check.ts

_testing_origin_check — the testing seam behind the cross-impl origin conformance table (origin_conformance.json): its input and output schemas, the pure check it answers with, its spec, and the action builder.

Split from testing_reset_actions.ts, whose other seams reach the in-process app server and through it the optional hono peer. This leaf is hono-free, so a consumer whose backend is a spawned Rust binary can run the conformance table without installing hono.

_testing_origin_check — run the origin allowlist's parse and request check for one {patterns, origin} pair, so the shared conformance table (origin_conformance.json) checks each backend's grammar and matcher over the wire, row by row. Pure: no database, no state. The Rust mirror is fuz_testing::create_testing_origin_check_action_spec.

Like _testing_action_manifest, it is not bundled by create_testing_actions: a consumer whose Rust binary doesn't mount the mirror would fail its action-manifest parity gate. The spine test binary appends it at the full-mount layer (build_full_spine_rpc_actions).

auth gates on the daemon-token credential, matching _testing_reset.
