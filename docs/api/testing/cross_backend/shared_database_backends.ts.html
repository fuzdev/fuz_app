testing/cross_backend/shared_database_backends.ts

Helpers for suites that run several spines over one Postgres database — the backend swap (backend_swap.ts, one backend at a time) and both spines live (backend_both_live.ts, at once). They share what a credential and a write need to carry from one spine to the other: the config checks, a snapshot of every table's content, the drain and invariant backdoors, and who a credential authenticates as on a given backend.
