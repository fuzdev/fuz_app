testing/db_invariants.ts

The per-test database invariant check — the hooks create_test_app and the cross-process setup register, over the invariants and their statement in db_invariant_queries.ts. In-process the check queries the test app's own Db (assert_db_invariants); cross-process it reads the backend's _testing_db_invariants backdoor (assert_db_invariant_rows).

Check a describe-scoped fixture's database once the describe's tests are done — the suite-level twin of the per-test hook, for a fixture built in beforeAll and shared by the describe (the per-describe round-trip and exposure suites), or a create_test_app app built there, which registers no per-test hook. Skipped when a test of the describe failed, or when no fixture was built. Call inside the describe, at collection. It registers an afterAll of its own, so it reads a fixture nothing closes in another afterAll; a describe that closes its app or database there calls check_db_invariants_after_suite in that hook, ahead of the close.

register_db_invariants_check
#

testing/db_invariants.ts view source

(check: () => Promise<void>): boolean import {register_db_invariants_check} from '@fuzdev/fuz_app/testing/db_invariants.js';

Run check when the current test finishes — the per-test hook the cross-process setup registers from setup_test(), with check the fixture's assert_db_invariants. create_test_app runs the same check in a hook of its own, which closes the app after it (and so every default_in_process_setup fixture).

Runs after the test body and its afterEach hooks, before the next test's setup resets the database. A test that already failed is left as it failed: its state proves nothing more. Outside a test — an app or fixture built in beforeAll, shared by a describe's tests — nothing is registered, and the suite checks the fixture once its tests are done (check_db_invariants_after_all).

Under describe.concurrent the hook attaches to whichever test vitest names current, and two tests' rows share one database, so a violation can fail a sibling of the test that left it; the shipped concurrent suite builds its fixture in beforeAll and is checked once after all its tests.
