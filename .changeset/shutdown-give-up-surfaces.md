- break: `AppServerOptions.auth_cleanup` is required, an `AuthCleanupSchedule` (`auth/cleanup.ts`): `{every_ms}` schedules `start_auth_cleanup` on that interval, `'off'` schedules nothing — twin of the Rust `fuz_auth::AuthCleanupSchedule` (`Every` / `Off`). There is no default: a server that omitted it (off) writes `auth_cleanup: 'off'`, one that passed `true` writes `{every_ms: DEFAULT_AUTH_CLEANUP_INTERVAL_MS}`, and `{interval_ms}` becomes `{every_ms}`. `create_test_app` passes `'off'`, which `app_options` can override. Assembly checks it with the other options, before acquiring anything, as the Rust backend build refuses a zero `Every`: anything but `'off'` or `{every_ms}` with a positive finite number of ms no greater than `PERIODIC_INTERVAL_MS_MAX` throws `create_app_server: auth_cleanup must be …` — an old-shape `true` or `{interval_ms}` included
