break: every narrow `*Rpc` adapter method takes its action's input as one params object and returns its output, both typed from the action specs; the params are optional where the input defaults to `{}`, and absent where the action takes no input. Changed: `AdminAccountsRpc.list_accounts(params?)`, `list_sessions(params?)`, `delete_account({account_id})`, `undelete_account({account_id})` and `retract_offer({offer_id})`; `RoleGrantOffersRpc.list(params?)`, `history(params?)`, `create(params: RoleGrantOfferCreateInput)`, `accept({offer_id})`, `decline({offer_id, reason})` and `retract({offer_id})`; `AdminInvitesRpc.list(params?)`; `AppSettingsRpc.get(params?)`; `AccountSessionsRpc` returns the `account_session_*` output types. `delete_account` keeps its params required, since its empty input deletes the caller. `AdminRpcApi`'s `admin_session_list`, `invite_list`, `app_settings_get`, `audit_log_list` and `audit_log_role_grant_history` take an optional input, matching the typed throwing client. An adapter over that client passes each call straight through (`accept: (params) => api.role_grant_offer_accept(params)`). `RoleGrantOffersState.submit_accept` / `submit_decline` / `submit_retract` take a `Uuid`, `RoleGrantOfferScope.scope_id` is a `Uuid`, `RoleGrantOfferCreateParams` is `RoleGrantOfferCreateInput` with the paired scope, and `RoleGrantOfferForm`'s `to_account_id` / `to_actor_id` props are `Uuid`s.
