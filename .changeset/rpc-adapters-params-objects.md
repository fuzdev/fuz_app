break: every narrow `*Rpc` adapter method takes its action's input as one params object and returns its output, both typed from the action specs; the params are optional where the input defaults to `{}`, and absent where the action takes no input. Changed: `AdminAccountsRpc.list_accounts(params?)`, `list_sessions(params?)`, `delete_account({account_id})`, `undelete_account({account_id})` and `retract_offer({offer_id})`; `RoleGrantOffersRpc.list(params?)`, `history(params?)`, `create(params: RoleGrantOfferCreateInput)`, `accept({offer_id})`, `decline({offer_id, reason})` and `retract({offer_id})`; `AdminInvitesRpc.list(params?)`; `AppSettingsRpc.get(params?)`; `AccountSessionsRpc` returns the `account_session_*` output types (`SessionListOutput`, `SessionRevokeOutput`, `SessionRevokeAllOutput`). `delete_account` requires its params and their `account_id` (non-null, non-optional), since its empty input deletes the caller. `AdminRpcApi`'s `admin_session_list`, `invite_list`, `app_settings_get`, `audit_log_list` and `audit_log_role_grant_history` take an optional input, matching the typed throwing client. `RoleGrantOffersState.submit_accept` / `submit_decline` / `submit_retract` take a `Uuid`, `RoleGrantOfferScope.scope_id` is a `Uuid`, `RoleGrantOfferCreateParams` is `RoleGrantOfferCreateInput` with the paired scope, and `RoleGrantOfferForm`'s `to_account_id` / `to_actor_id` props are `Uuid`s. To migrate: pass each adapter call its action's params object — `list_accounts(include_deleted)` is `list_accounts({include_deleted})`, `delete_account(account_id)` is `delete_account({account_id})`, `accept(offer_id)` is `accept({offer_id})`, `decline(offer_id, reason)` is `decline({offer_id, reason})` — so an adapter over the typed throwing client passes each call straight through (`accept: (params) => api.role_grant_offer_accept(params)`)
