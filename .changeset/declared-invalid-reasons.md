break: an action input field can declare the `error.data.reason` its refusal carries — `invalid_reason` in its `.meta()` (`SchemaFieldMeta`) — and the RPC dispatcher (HTTP and WS, via `perform_action`'s new `to_invalid_params_error`) answers every `invalid_params` whose first Zod issue lands on that field with it, the message staying `invalid params` and the issues staying DEV-only; a local `ActionEvent` parse puts the same `reason` beside its `validation_errors`. A body with an unknown key on the input itself answers no reason, whatever else is wrong with it. Declared reasons are named `<field>_invalid`: the paged reads now declare `limit_invalid` / `offset_invalid` (and `audit_log_list` `since_seq_invalid` / `outcome_invalid`), and `account_token_create` `token_scope_invalid` / `token_lifetime_invalid` (its over-cap scope refusal included), matching the Rust spine — new constants `ERROR_LIMIT_INVALID`, `ERROR_OFFSET_INVALID`, `ERROR_SINCE_SEQ_INVALID`, `ERROR_OUTCOME_INVALID` (`http/error_schemas.ts`) and `ERROR_TOKEN_SCOPE_INVALID`, `ERROR_TOKEN_LIFETIME_INVALID` (`auth/account_action_specs.ts`), and `schema_invalid_reason` / `resolve_invalid_reason` / `resolve_issues_invalid_reason` (`schema_meta.ts`), `zod_get_schema_layers` (`zod.ts`). The generated params cases now name the field they break (`InputTestCase.field`), and `describe_rpc_adversarial_cross_tests` (which expected no reason) and `describe_rpc_attack_surface_tests` (which did not check `data.reason`) now expect each case's declared reason (`expected_invalid_reason`) — a consumer backend that answers a declared field's refusal without that reason, on any case kind, now fails them. To migrate: declare `invalid_reason` on your own input fields where your backend names a reason on schema refusals, drop any `xfail_params` rows that tracked the token-create or pagination reasons, and match the new reason strings where a client compared a Rust backend's `limit_out_of_range`, `offset_negative`, `since_seq_negative`, `invalid_token_scope` or `invalid_token_lifetime`
