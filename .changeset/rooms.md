feat: rooms over a WebSocket endpoint — the twin of the Rust spine's `fuz_realtime::RoomRegistry` and `fuz_actions::room`; breaking for cross-backend configs, which now state the `rooms` mount flag

- `actions/room_registry.ts`: `RoomRegistry` (`new RoomRegistry(connections, options)`) seats members in rooms keyed by a consumer's `RoomId`, each seat with a random `MemberId`, relays opaque payloads to one member or the room, holds a small member state, and serves occupancy watches; every room event carries a per-room `seq`. Joins and watches run in two phases (`reserve_seat` / `admit_seat`, `reserve_watch` / `admit_watch`) around the consumer's authorizer, so an `evict(target, reason)` landing mid-authorizer still reaches the request; `exclusive` keeps one seat per actor across the registry, newest admitted winning, with a rejoin tombstone (`rejoin_of` → `seat_moved`). A connection's seats and watches are released when its socket closes, through one listener per connection
- `actions/room_action_specs.ts`: the six WS-only verbs (`room_join`, `room_leave`, `room_send`, `room_state_set`, `room_watch`, `room_unwatch`, in `all_room_action_specs`) and the six `room_*` notifications (`room_notification_action_specs`, `room_notification_actions` for a WS action list), their schemas, the `ERROR_ROOM_*` reasons, the `DEFAULT_ROOM_*` bounds, and `json_escaped_len`, the bytes a payload or state adds to a frame (byte for byte the Rust count; a lone surrogate counts 6, as `JSON.stringify` writes it)
- `actions/room_actions.ts`: `create_room_actions({registry, authorize, limiter}, {join_extra?})` builds the verbs — mount them on a `ws_endpoints` entry only, never an RPC endpoint. `RoomAuthorize.authorize({actor_id, account_id, room_id, access}, db)` decides each join and watch on a read of its own (never the request's role grants); `{allow: false}` answers `room_not_found`. `room_join` and `room_watch` take the per-account rate-limit class; `RoomRateLimiter` (`DEFAULT_ROOM_RATE_LIMIT`) bounds each connection's joins, sends, and state sets by count and escaped bytes, and `create_room_actions` throws when it can't cover a max-size payload or state (`check_room_limits`)
- `ConnectionRegistry.socket_signal(connection_id)`: an admitted connection's socket signal, which every close path aborts
- `auth/role_grant_queries.ts`: `query_actor_has_active_global_role(deps, actor_id, role)`, the actor-keyed live read of a global grant
- testing: the action manifest marks a WebSocket-only method `transport: 'ws'` and omits the key on every other entry, so a manifest with no WebSocket-only method is unchanged (`build_action_manifest(specs, ws_only_specs?)`, `create_testing_action_manifest_action(mounted, ws_only?)`); `ActionManifestEntry` accepts the optional key
- testing: `_testing_room_evict` (`create_testing_room_evict_action(registry)`, mirrored by `fuz_testing::create_testing_room_evict_action_spec`) joins `TESTING_BACKDOOR_METHODS`; a backend that doesn't mount it leaves it out of `capabilities.testing_backdoors`, as with the other backdoors
- break: a cross config declaring the whole `TESTING_BACKDOOR_METHODS` list now declares `_testing_room_evict`, so it must mount it (over its `RoomRegistry`) or filter it out (`TESTING_BACKDOOR_METHODS.filter((m) => m !== '_testing_room_evict')`) — the testing-backdoor suite refuses a declared backdoor the backend answers `method_not_found`
- testing: `describe_rooms_ws_cross_tests` (`cross_backend/rooms_ws.ts`), run by `describe_spine_cross_suites` as `rooms_ws`, gated on `capabilities.rooms`, which requires `_testing_room_evict` in `testing_backdoors` (as `fact_serving` requires `_testing_put_fact`), and `test_room_authorize` (`cross_backend/test_room_authorize.ts`), the twin of the Rust stub's `TestRoomAuthorize`
- break: `BackendCapabilities` gains the `rooms` mount flag, which has no family default — every cross-backend config adds `rooms: false` to its `capabilities` (or `true` for a test binary mounting the room verbs over `test_room_authorize` and an exclusive registry), or fails typecheck naming it
